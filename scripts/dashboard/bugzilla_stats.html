5. Yocto Weekly Open Bug Trend: Weighted Defect Density

Note: How do we calculate the data of "weighted defect density"? We define a weight for each severity. And the sum of these weights for all open bugs are the data we record in the chart. The weight we use for each severity:

  • Critical: 10
  • Major: 7
  • Normal: 5
  • Minor: 3
  • Enhancement: 0
  • Janitors: 0

6. Yocto Weekly Open Bug Trend: Weighted Defect Density Plus

Note: "weighted defect density plus" shows "weighted defect density" divided by total open project bugs. This is intended to indicate if the general defect density is increasing or not as the project as a whole grows.
